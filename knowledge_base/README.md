# 团队本地知识库（2026-09-18整合版）

本版已整理队友提供的新知识库：

- 可检索Word资料：27份；
- 图片素材：2张；
- 知识库说明与来源记录：3份。

目录说明：

- `documents/`：参与系统检索的教案、讲义、课标、习题、跨学科案例和课堂实录；
- `assets/images/`：思维导图和解题流程图，供后续PPT配图扩展；
- `compliance/`：资料来源与知识产权说明，不参与日常检索；
- `manifest.json`：可选的人工标题和来源补充，本版由系统根据文件夹自动分类。

以后增加资料时，放入 `documents/对应类别/`，再在网页中点击“同步团队知识库”。支持DOCX、PDF、PPTX、TXT和Markdown。扫描版PDF需先OCR；图片目前作为素材保留，不参与文字检索。

使用前仍建议团队抽查题目答案、教材原文表述和来源链接，避免把整理材料误称为官方教材原文。
